# 字幕时间轴校准工作台

面向字幕校对人员的时间轴校准工具，基于 Vue 3 + TypeScript + Vite，解决三类问题：

- 整段字幕整体提前/延后：多选后批量平移，先预览再确认，越过零点整批拒绝。
- 局部重叠：列表与时间轴醒目标红，点击冲突标记即可定位相关字幕；首尾相接不算冲突。
- 修改难以回退：每次拖拽或批量确认只产生一步撤销，撤销/重做同时恢复文本、时间与选中状态。

## 启动

Node.js 22.16.0、npm 10.9.2，依赖版本锁定在 `package-lock.json`。

```bash
npm ci
npm run dev      # 开发服务器，默认 http://127.0.0.1:5173/
npm run build    # 类型检查 + 生产构建
npm test         # 运行 Vitest（24 个用例，覆盖解析、冲突、平移、历史与界面挂载）
```

## 操作方式

1. **导入/载入**：工具栏“导入 SRT（UTF-8）”选择本地 `.srt`（兼容 BOM、CRLF/LF、缺编号块、逗号或点毫秒），或“载入示例”查看一段包含整体偏早提示、首尾相接与局部重叠的样片数据。解析失败时会列出出错字幕编号与原因，当前文档保持不变。
2. **定位联动**：左侧列表按开始时间展示序号、开始/结束、时长与多行文本；右侧时间轴自动泳道排布。点击任意一处，另一处与下方检查器同步选中。Ctrl/点击多选、Shift 区间多选。
3. **编辑时间与文本**：检查器以毫秒精度编辑开始/结束（支持 `HH:MM:SS,mmm` 与 ±1ms 按钮）和多行文本，Enter 或“确认修改”才写入；非法（负开始、开始不早于结束、空文本）会被拒绝，未确认草稿不会影响已保存结果。
4. **拖拽校准**：时间轴上拖动字幕块整体平移（多选时一起移动），拖动左右边缘调整时长；Esc 取消本次拖拽。一次拖拽（无论移动多远）只算一步撤销。
5. **批量平移**：多选后点击“批量提前/延后”，输入毫秒数（负值提前），弹窗列出每条字幕的变化预览；任一条开始时间会越过零点则整批拒绝，文档原样保留。
6. **撤销/重做**：工具栏按钮或 `Ctrl+Z` / `Ctrl+Y`，恢复文本、时间与选中状态；产生新修改后重做记录清空。
7. **播放头**：点击/拖动顶部标尺移动播放头，“播放”按实际时间推进。当前时刻面板显示全部有效字幕（区间含开始、不含结束），重叠时全部列出。
8. **缩放**：缩放滑杆、“适应宽度”，或在时间轴上按住 Ctrl 滚动鼠标滚轮。
9. **导出**：“导出 SRT”按开始时间稳定排序（同开始保持原相对顺序）、从 1 连续编号，完整保留多行文本，下载为 `calibrated.srt`。

## 目录结构

- `src/lib/srt.ts`：SRT 解析、序列化、毫秒时间戳。
- `src/lib/timeline.ts`：冲突检测、播放头命中、批量平移校验、时间合法性。
- `src/lib/history.ts`：单步撤销/重做栈。
- `src/stores/workbench.ts`：文档状态、选择联动、拖拽事务、导入导出。
- `src/components/`：`Toolbar`、`CueList`、`Timeline`、`Inspector`、`PreviewPanel`。
- `src/__tests__/`：核心库、状态与组件测试。
