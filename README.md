# 字幕时间轴校准工作台

面向字幕校对人员的时间轴校准工具，基于 Vue 3 + TypeScript + Vite，解决整段字幕提前/延后、局部时间重叠、改动后难以回退的问题。

## 启动

Node.js 22.16.0、npm 10.9.2，依赖版本锁定于 `package-lock.json`。

```bash
npm ci
npm run dev      # 开发页面，默认 http://127.0.0.1:5173/
npm run build    # 类型检查 + 生产构建
npm test         # 运行 vitest 单元/组件测试
```

若终端找不到 node 或误用了 Windows npm：

```bash
export PATH="/home/hj/.local/share/cc-codex/toolchains/node-v22.16.0-case002/node-v22.16.0-linux-x64/bin:$PATH"
```

## 功能

- **导入与示例**：导入 UTF-8（支持 BOM）SRT，兼容 CRLF/LF、逗号或点毫秒、省略序号等常见写法，保留多行文本；也可一键载入内置冲突示例。解析失败时提示“第 N 条字幕”及具体原因，且不会用残缺结果覆盖当前文档。
- **列表与时间轴**：左侧按开始时间列出序号、开始/结束、时长与多行文本；右侧为可缩放时间轴。在任一处选中字幕，另一处自动同步滚动定位。
- **编辑**：编辑面板可按毫秒精度修改文本与起止时间（`HH:MM:SS,mmm`，↑/↓ 微调 100ms）；开始时间不得为负且必须早于结束，未保存的输入不会影响已确认结果。时间轴可拖动字幕块整体移动、拖动左右两端调整时长。
- **冲突检测**：允许重叠，重叠字幕红色高亮；列表显示“N 条冲突”按钮可定位整组相关字幕，时间轴双击冲突块也可全选同组。首尾相接（一条结束等于另一条开始）不算重叠。
- **多选与批量平移**：Ctrl/⌘+单击多选，可统一提前/延后 0.5 秒或输入任意毫秒数；先弹出预览表格，若任一字幕调整后越过 00:00:00,000，整批拒绝且文档保持原样。
- **撤销/重做**：一次拖拽、一次批量确认、一次保存各算一步；撤销与重做同时恢复文本、时间和选中状态；任何新修改都会清空重做记录。快捷键 `Ctrl/⌘+Z`、`Ctrl/⌘+Y`（或 `Ctrl/⌘+Shift+Z`）。
- **键盘平移**：非输入框聚焦时，方向键平移选中字幕 10ms，按住 Shift 为 100ms。
- **播放头**：播放/暂停、±1 秒或点击标尺移动播放头；预览当前时刻全部有效字幕（时间区间含开始、不含结束），重叠时同时显示。
- **导出**：按开始时间排序（同开始保持原相对顺序）、重新连续编号导出 SRT，多行文本原样保留。

## 代码结构

- `src/subtitle/srt.ts`：SRT 解析、时间码、序列化（含错误类型 `SrtParseError`）
- `src/subtitle/timeline.ts`：重叠判定、冲突分组、泳道分配、播放时刻查询、批量平移校验
- `src/subtitle/history.ts`：带选择状态的撤销/重做栈
- `src/subtitle/store.ts`：全局响应式状态与操作
- `src/components/TimelineView.vue`、`CueList.vue`、`CueEditor.vue`：三大界面区域
- `src/**/*.test.ts`：解析/序列化、冲突、泳道、平移、历史与界面冒烟测试
